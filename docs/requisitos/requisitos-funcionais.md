# Requisitos Funcionais

Sistema de Gestão de Recebíveis com Split de Pagamentos.

- **RF01 — Cadastrar beneficiários:** o sistema deve permitir cadastrar beneficiários, informando nome, tipo de pessoa, documento e dados bancários.
- **RF02 — Consultar beneficiários:** o sistema deve permitir consultar os beneficiários cadastrados e seus respectivos status.
- **RF03 — Aprovar beneficiários:** o sistema deve permitir aprovar beneficiários pendentes.
- **RF04 — Cadastrar recebíveis:** o sistema deve permitir cadastrar recebíveis, informando descrição, valor e data de liquidação.
- **RF05 — Consultar recebíveis:** o sistema deve permitir consultar os recebíveis cadastrados.
- **RF06 — Criar Split:** o sistema deve permitir criar um Split.
- **RF07 — Listar Splits:** o sistema deve permitir listar os Splits e seus respectivos status.
- **RF08 — Editar Split pendente:** o sistema deve permitir editar um Split pendente.
- **RF09 — Excluir Split pendente:** o sistema deve permitir excluir um Split pendente.
- **RF10 — Executar Splits agendados:** o sistema deve permitir executar Splits agendados.
- **RF11 — Recusar Split sem saldo:** o sistema deve recusar um Split quando não houver saldo suficiente.
- **RF12 — Histórico de Splits:** o sistema deve permitir consultar o histórico de Splits.
- **RF13 — Prioridade na mesma data:** o sistema deve respeitar a prioridade de Splits agendados para a mesma data.
- **RF14 — Relatório resumido:** o sistema deve gerar um relatório resumido das operações.
