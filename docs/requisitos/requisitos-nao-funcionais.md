# Requisitos Não Funcionais

- **RNF01 — Linguagem:** o sistema deverá ser desenvolvido em Java.
- **RNF02 — Build:** o projeto deverá utilizar Maven.
- **RNF03 — Testabilidade:** as regras de negócio deverão ser estruturadas de maneira que possam ser testadas unitariamente.
- **RNF04 — Cobertura:** as classes de serviço/regras deverão atingir pelo menos 80% de cobertura.
- **RNF05 — BDD:** o sistema deverá possuir pelo menos 5 cenários BDD automatizados.
- **RNF06 — Arquitetura:** o projeto deverá utilizar quatro camadas: `domain`, `service`, `infra` e `ui`.
- **RNF07 — Versionamento:** o código deverá ser mantido em GitHub, com histórico de commits descritivos.
- **RNF08 — Revisão:** deverá existir pelo menos um Pull Request revisado por Sprint.
- **RNF09 — Documentação:** o README deverá permanecer atualizado.
- **RNF10 — Usabilidade:** a interface deverá apresentar mensagens claras ao usuário e orientar as operações.
